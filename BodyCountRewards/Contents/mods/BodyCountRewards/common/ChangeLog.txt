[ v1.4.0 - Body Count Rewards ]

FIXES & IMPROVEMENTS
- Reworked "Retroactive Rewards". While the option is OFF, every milestone you already passed without a reward is set aside when you load the save instead of being handed out slowly. Turn the option ON and load again to claim everything set aside - each reward is granted exactly once.
- Fixed the reward system getting stuck when no traits were left: the retry loop now stops and the "All rewards granted!" message appears.
- Multiplayer: a lost or slow reward request is retried automatically instead of waiting for your next kill.
- Multiplayer: reward notifications now use each player's own game language.
- Trait names for addon traits with unusual translation keys now resolve properly instead of showing a raw ID.
- Missing translations now fall back to readable text instead of showing internal key names.
- Fixed number formatting in languages that use "." as the thousands separator.
- Controller users no longer lose the right-click submenu.
- Old reward popups and the stats window no longer carry over from a previous character into a new session.
- Loading a save no longer reports your lifetime kill count as newly earned kills.
- Saves are repaired on load when reward counters or the reward history are damaged or oversized.
- Stats window: removed-trait history rows are labeled correctly, long translated labels no longer overlap their values, and the catalog sorts consistently.
- Large multiplayer reward batches no longer rebuild the stats window repeatedly, so the UI stays smooth.

[ v1.3.4 - Body Count Rewards ]

FIXES & IMPROVEMENTS
- Duplicate-grant fix: occasionally, traits already owned could be re-granted at milestones if the server had sync issues; now guarded by BCR's own grant history.
- Added "Restore Missing Traits" sandbox option (default off). Another guard against sync-issues. Missing earned traits get marked lost (re-earnable) or auto-reapplied when enabled.
- Fixed broken characters in some sandbox translations
- Added Japanese translation
- Thanks to "road to 1 mmr" for the duplicate trait report.

[ v1.3.1 - Body Count Rewards ]

FIXES & IMPROVEMENTS
- Fixed trait exclusion bugs where conflicting traits could be double-granted.
- Corrected several trait point costs to match vanilla B42.19 values.
- Cached config and trait lookups - less per-tick overhead.
- Slight overhaul of the "Trait catalouge" Tab in the UI to support "Addon Mods", see "THIRD-PARTY TRAIT API"-Section down below  

NEW OPTIONS
- Enable Debug Logging sandbox option - for sending me log files when things break.
- Show Context Menu toggle in the ESC menu - hides the right-click entry if it annoys you.

NEW LANGUAGES
- Auto-translated support for a whole bunch of languages across sandbox options and the stats UI. Machine-generated, so if something reads like a bad fever dream, let me know in the Steam Workshop thread.

THIRD-PARTY TRAIT API
- Other modders can now register their own trait packs with BCR. Custom traits merge into the reward pools, stats UI, and history - no hacks needed. Check the "I Am Not Your Mom" addon for a working template.
- Example Mod can be found at "BodyCountRewards (Addon) - I Am Not Your Mom" [Mod ID: BCR-IAmNotYourMom[ [Workshop ID: 3745224257] (https://steamcommunity.com/sharedfiles/filedetails/?id=3745224257)
