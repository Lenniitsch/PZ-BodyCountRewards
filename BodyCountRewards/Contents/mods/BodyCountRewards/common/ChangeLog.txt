[ v1.3.4 - Body Count Rewards ]

FIXES & IMPROVEMENTS
- Fixed: traits a player already had (starting traits, previously earned traits) could be granted again at a kill milestone. BCR now records a trait baseline at first check and guards reward pools with its own grant history. This protects against grants made while the engine's trait list is wrong (for example right after a save load or a multiplayer sync resets it).
- Added "Restore Missing Traits" sandbox option (Default: Off). When a BCR-earned trait is missing from a player (multiplayer desync, admin removal), BCR marks it as lost so it can be re-earned through milestones. With the option enabled, the trait is re-applied automatically instead.
- Fixed: broken characters in the sandbox translations for German, French, Polish, Portuguese (BR), Russian, Turkish, Korean, Chinese and Ukrainian. Files were recovered and re-encoded.
- Added: Japanese translation (UI + sandbox options), using the official vanilla trait names.
- Hardened the multiplayer reward path: the server now ignores client-reported kill counts entirely and uses only its own authoritative kill counter. Reward batches are capped and stop early when the pools run dry, so a hacked client can no longer hang the server or claim milestones it never earned.
- Fixed: reward processing and trait-state reconciliation were inactive in singleplayer due to a wrong server-only guard. The duplicate-grant protection now works in SP too.
- Fixed: the stats UI catalog no longer reorders the shared trait lists; invalid addon registrations are now correctly reported as skipped.
- Improved: the sandbox options page. "Restore Missing Traits" and "Debug Logging" now sit at the bottom, and boolean labels drop the redundant "Enable" prefix in all 12 languages.
- Thanks to "road to 1 mmr" for the duplicate trait report.

[ v1.3.1 - Body Count Rewards ]

FIXES & IMPROVEMENTS
- Fixed trait exclusion bugs where conflicting traits could be double-granted.
- Corrected several trait point costs to match vanilla B42.19 values.
- Cached config and trait lookups - less per-tick overhead.
- Slight overhaul of the "Trait catalouge" Tab in the UI to support "Addon Mods", see "THIRD-PARTY TRAIT API"-Section down below  

NEW OPTIONS
- Enable Debug Logging sandbox option - for sending me log files when things break.
- Show Context Menu toggle in the ESC menu - hides the right-click entry if it annoys you.

NEW LANGUAGES
- Auto-translated support for a whole bunch of languages across sandbox options and the stats UI. Machine-generated, so if something reads like a bad fever dream, let me know in the Steam Workshop thread.

THIRD-PARTY TRAIT API
- Other modders can now register their own trait packs with BCR. Custom traits merge into the reward pools, stats UI, and history - no hacks needed. Check the "I Am Not Your Mom" addon for a working template.
- Example Mod can be found at "BodyCountRewards (Addon) - I Am Not Your Mom" [Mod ID: BCR-IAmNotYourMom[ [Workshop ID: 3745224257] (https://steamcommunity.com/sharedfiles/filedetails/?id=3745224257)
